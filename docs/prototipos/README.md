# Protótipos de tela

Capturas do protótipo navegável, em 1366 px salvo indicação. Perfis: usuário comum (03 a 06), responsável de bloco (07 a 11) e administrador (12 a 16). As telas de responsável e administrador seguem o mesmo layout; o que muda é o menu lateral e o escopo dos dados.
